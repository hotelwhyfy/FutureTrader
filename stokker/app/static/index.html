Parameters are chosen using only each fold's training window, then applied blind to the next unseen year. The stitched test slices are the only honest curve. This does not narrow confidence intervals — test windows are shorter than the full sample, so out-of-sample Sharpe carries a wider interval. It measures how much of a backtest was fitting, not whether the strategy works.

Rolls come from each contract's delivery calendar, never from price. An earlier statistical detector flagged the 2010 flash crash, Brexit, Volmageddon and the COVID selloff as “rolls” and zeroed them — inflating ES cumulative return by ~0.6 log units by deleting the left tail. Price-based roll detection cannot work: adjacent equity-index contracts differ by basis points, far below daily volatility.
